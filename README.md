# Building practical AI tools, in the open

I'm Hussein, an AI product builder based in Muscat. I work on developer tools, AI agents, MCP integrations, and useful automations through **NabuXAI** and **MrChatGPT**.

> **Free core, lasting value.** I favor tools with a useful free core, clear documentation, transparent dependencies, and the freedom to self-host when practical. Paid infrastructure or external model APIs, if any, should be disclosed rather than hidden.
